# 응대 필요 판단 기준 (초안 v0, 2026-10-28)

> 초안이다. 근거는 `reply-references-triage-evidence.md`(5절)와 `reply-references-platform-legal.md`. 확정되면 리뷰 분류 AI의
> 지시문과 출력 형태를 이 기준에 맞춰 다시 쓰고, 평가 세트로 다시 측정한다.

## 1. 정의 (별점과 무관)

> **판매자가 무언가 하지 않으면, 그 고객이나 다음 구매자에게 해결되지 않은 문제 · 위험 · 오해가 남는 리뷰.**

별점은 판단 재료일 뿐 기준이 아니다. ★5에 질문이나 불량이 있으면 응대 대상이고, ★2가 「그냥 별로」뿐이면 낮은 순위다.

## 2. 범주와 기본 행동

| 코드 | 범주 | 신호 예 | 기본 행동 |
|---|---|---|---|
| S | 안전 · 건강 위해 주장 | 다침 · 화상 · 발진 · 알레르기 · 이물 · 변질 · 발화 · 어린이 삼킴 | 사람 확인 필수, 즉시 알림. 짧은 공감 + 연락 경로. 법정 보고 의무 검토 표시 |
| L | 법적 · 분쟁 신호 | 고소 · 소보원 · 공정위 · 사기 | 사람 확인 필수. 비난 없는 짧은 답글. 공개 사실 다툼 금지 |
| R | 해결 요청이 담긴 거래 문제 | 환불 · 교환 · 반품 요청, 누락 · 파손 · 오배송 · 지연 · 불량 | 인정 + 해결 경로. 보상은 문의 · CS로 |
| Q | 질문 | 사용법 · 호환 · 재입고 · 사이즈 · 성분 | 공개 답글로 답함(다음 구매자도 읽음) |
| D | 구체적 품질 불만(요청 없음) | 「박음질이 풀렸어요」 「색이 설명과 달라요」 | 맞춤 답글. 결함이면 인정 · 조치, 오해면 설명 |
| M | 혼합 — 구체적 아쉬움 | 「좋은데 사이즈가 작아요」 | 아쉬운 부분에 구체적으로 |
| V | 막연한 불만 | 「별로예요」 「그냥 그래요」 | 낮은 순위, 짧게 |
| X | 신고 대상 | 다른 상품 · 다른 판매자, 욕설 · 혐오, 개인정보, 광고, 가짜 의심 | 답글보다 신고 검토(별도 줄). 불리하다는 이유만으로 숨기기 금지 |
| P | 순수 칭찬 | 요청 · 질문 · 아쉬움 없음 | 응대 불필요가 기본(미리 쓰지 않음). 쓴다면 짧고 구체적으로 |

겹치면 높은 범주를 따르고 나머지는 답글에서 함께 다룬다(S+R → S로 처리하되 환불 경로도 안내).

**「응대 필요」 = S · L · R · Q · D · M.** V는 일관성 차원에서 짧게(미리 쓰기는 판매자 선택), X는 신고 줄, P는 응대 불필요.

## 3. 순서

S → L → R → Q → D → M → V → (X는 별도 줄) → P. 같은 범주 안에서는 오래 기다린 것, 사진 · 긴 리뷰처럼 다음 구매자에게 많이
보이는 것 먼저. 응답 목표 후보: S · L 당일, R · Q · D 2일, M · V 1주(근거는 S만 법정 해석, 나머지는 벤더 · 설문 권고치).

## 4. 지금 시스템과의 차이

- 지금의 판단은 리뷰 분류 AI(지시문 v4)의 단계(확인 필요 / 지켜보기 / 참고)와 권하는 조치로 「응대 필요」를 읽는다
  (`AiTriagePilotService#needsResponse`). 범주(S · L · R · Q · D · M · V · X · P)를 직접 내지 않는다.
- 기준대로 하려면 분류 AI가 범주를 내게 출력 형태와 지시문을 바꿔야 하고, 지시문 v4의 측정은 그때 다시 해야 한다(지시문을 바꾸면
  측정 결과가 무효가 된다는 규칙이 그 파일에 있다).
- 안전 단어(`ReviewSafetySignal`)는 지금 순서에서만 쓰인다. 기준에서는 S가 판단 자체의 첫 범주다.
- 「이 리뷰에 무언가 필요한가」를 지금 다섯 곳이 따로 읽는다(`cleanup-inventory.md` 2-6). 기준이 확정되면 하나로 모은다.

## 5. 정해 주실 것

1. ★4~5 순수 칭찬(P)에 답글을 아예 두지 않을지, 판매자가 원할 때만 짧게 쓸지 — 연구 결론이 엇갈린다(지금 기본값은 「누를 때 쓰기」).
2. V(막연한 불만)를 미리 쓸지.
3. 쿠팡처럼 리뷰가 판매자 간 공유되는 채널에서 「다른 판매자분」 리뷰를 X로 볼지.
4. 응답 목표 시간을 화면에 숫자로 보여 줄지.
5. 리뷰가 제품안전기본법상 「알게 된」 시점이 되는지 — 법률 자문 필요(제품 결정 아님).
