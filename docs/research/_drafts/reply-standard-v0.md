# 좋은 답글 기준표 (초안 v0, 2026-10-28)

> 초안이다. 사장님이 확정하면 이 표에서 초안 지시문(`AgentDraftPrompt`)과 검사 규칙을 다시 뽑는다 — 지금의 규칙에 덧붙이지
> 않는다. 근거는 같은 폴더의 세 조사 초안(`reply-references-platform-legal.md` · `-best-practice.md` · `-triage-evidence.md`)이고
> 각 줄 끝의 [ ]가 그 출처 번호다. 특정 판매자·상품에 맞춘 규칙은 없다. 판매자마다 다른 것(말투 · 정책 · 상품 사실)은 판매자
> 설정과 등록된 지식에서 온다.

## 1. 어떤 답글에도 지키는 것

### 1-1. 쓰지 않는 것 (법 · 플랫폼 — 어기면 판매자가 제재받는다)

| # | 규칙 | 근거 |
|---|---|---|
| N1 | 구매자 실명 · 주문번호 · 주소 · 전화 · 구매 이력을 공개 답글에 쓰지 않는다. 리뷰에 적힌 건강 정보도 되풀이하지 않는다. | 개인정보보호법 §18·§59, 전자상거래법 §21①6 [법 R1] |
| N2 | 외부 연락처 · 자사몰/다른 마켓 주소 · 계좌 · 외부 링크를 넣지 않는다. 연락은 플랫폼 안 경로로만. | NAVER 직거래 정책 · Npay 약관 §22 [법 R2] |
| N3 | 리뷰를 쓰거나 고치거나 지우는 대가(적립금 · 쿠폰 · 사은품)를 제안하지 않고, 리뷰 수정 · 삭제를 요청하지 않는다. | 공정위 추천·보증 심사지침(2026-06 개정) [법 R3, 실무 12] |
| N4 | 후기를 실제보다 좋게 바꿔 인용하지 않고, 리뷰에 없는 효과 · 평가를 덧붙이지 않는다. | 심사지침 Ⅳ.1 [법 R4] |
| N5 | 식품 · 건강식품 · 화장품 · 의료기기에 질병 예방 · 치료 · 개선 효능을 쓰지 않고, 구매자의 효능 주장에 맞장구치지 않는다. | 식품표시광고법 §8, 의료기기법 §24 [법 R5] |
| N6 | 근거 없는 최상급 · 「유일」, 경쟁사 비교 · 비하를 쓰지 않는다. | 표시광고법 §3 [법 R6] |
| N7 | 작성자를 비난하거나 단정하지 않는다(거짓말 · 블랙컨슈머). 「삭제/신고하겠다」를 쓰지 않는다. | 정보통신망법 §70, NAVER 신고 기준, 불만 후기 은폐 제재 [법 R7·R8] |
| N8 | 반품 · 교환 안내를 법보다 불리하게 쓰지 않는다: 7일 미만 기한, 「개봉하면 반품 불가」 단정(내용 확인 개봉은 예외), 하자 · 오배송인데 구매자 반품비. 하자 · 표시와 다름은 받은 날부터 3개월 · 안 날부터 30일. | 전자상거래법 §17·§18 [법 R9·R10] |
| N9 | 판매자가 정하지 않은 약속을 쓰지 않는다: 금액 · 배상 · 재발송 · 사은품 · 도착일 · 재입고일 · 「조치 완료」. 판매자 정책이나 판매자 입력에 있을 때만. 없으면 경로 안내에서 멈춘다. | 소비자분쟁해결기준, AI 답글이 하지 않은 조치를 암시한 연구(2026) [법 R11, 실무 8] |
| N10 | 판매자 목소리임을 흐리지 않는다 — 구매자나 제3자를 가장하지 않는다. | 심사지침 Ⅴ [법 R18] |

### 1-2. 반드시 하는 것 (좋은 답글 — 효과 근거가 가장 강한 부분)

| # | 규칙 | 근거 |
|---|---|---|
| G1 | 그 리뷰에만 있는 지점을 하나 이상 짚는다(칭찬한 점 · 지적한 문제 · 질문). 다른 리뷰에 붙여도 말이 되는 답글은 실패다. | 천편일률 답글은 효과를 깎는다 — 학술 3건 + Google · Bazaarvoice · 설문 [실무 1, 판단 근거] |
| G2 | 리뷰에 질문이 있으면 답한다(판매자 사실로) — 사실이 없으면 그 질문은 사람에게 넘긴다. 질문을 건너뛴 답글은 내보내지 않는다. | Google · Trustpilot [실무 2] |
| G3 | 불만은 리뷰가 말한 그 문제를 이름으로 부르고, 사과는 문제를 지목한 뒤 한 번. 결함엔 인정 · 조치, 절차 불만엔 설명 · 조치, 태도 불만엔 공감. | Li 외 2018, Ravichandran·Deng 2023 [실무 3, 판단 근거] |
| G4 | 고객이 이미 해 본 방법은 다시 권하지 않는다. 되짚고, 그다음 단계(새 정보 하나 또는 교환·반품·문의 경로)만. | [실무 4] — 이번 평가의 실제 결함 |
| G5 | 새 정보(사용 팁 · 특성 설명 · 개선 소식)는 판매자가 등록한 사실에서만. 근거끼리 다르면 그 항목은 쓰지 않는다. | [실무 5] |
| G6 | 칭찬에 아쉬움이 섞이면 아쉬움을 빼먹지 않는다. ★3 · 미지근한 리뷰에 「만족하셨다니」 전제를 쓰지 않는다 — 유형은 별점이 아니라 본문으로. | [실무 6·7] |
| G7 | 원인 설명은 사실일 때 한 줄. 택배사나 고객 탓으로 돌리지 않는다. | [실무 9·10] |

### 1-3. 형식

| # | 규칙 | 근거 |
|---|---|---|
| F1 | 짧게: 칭찬 1~3문장, 불만은 해결 경로까지 한 단락. 리뷰보다 긴 답글은 다시 본다. NAVER 리뷰 답글 5~200자(일괄 기준 확인, 개별 상한 미확인). | [실무 17, 법 R12] |
| F2 | 같은 판매자의 최근 답글과 여는 말 · 닫는 말 · 핵심 문장이 겹치면 다시 쓴다. 고정 인사 + 고정 다짐 틀이 템플릿 신호다. | [실무 19] |
| F3 | 감정 과장(감동 · 눈물 · 큰 힘)을 기본값으로 쓰지 않는다. 사물 존대(「품절이십니다」)를 쓰지 않는다. | [실무 20·21] |
| F4 | 문체는 판매자 설정 하나(해요체 · 하십시오체), 한 답글 안에서 섞지 않는다. | [실무 22, 근거 약 — 판매자 설정] |
| F5 | 첫 등록본이 구매자에게 알림으로 가고 문의 답변은 지울 수 없다 — 「나중에 고치면 된다」를 전제로 쓰지 않는다. | NAVER [법 R14] |

## 2. 리뷰 유형별 뼈대

문장이 아니라 순서다. 실제 문장은 그 리뷰와 판매자 사실에서 나온다.

| 유형 | 뼈대 | 하지 않는 것 |
|---|---|---|
| 칭찬 | 짧은 감사 → 고객이 칭찬한 그 지점 → (판매자가 아는 사실 한 줄, 있으면) | 「소중한 후기 감사합니다」만으로 끝내기 · 사과 · 개선 다짐 |
| 칭찬 + 작은 아쉬움 | 칭찬 받기 → 아쉬움 그대로 인정 → 개선됨 / 특성 설명 / 전달 중 하나(사실 있을 때) | 아쉬움 건너뛰기 |
| ★3 · 미지근함 | 감사 → 아쉬웠다고 한 항목 → (사실 있을 때) 안내 | 만족 전제 |
| 불량 · 파손 | 결함 지목 → 인정 · 사과 1회 → 고객이 이미 한 조치 되짚기 → 정책 안의 해결 경로 → 비공개 안내 | 원인 짐작 · 고객 사용법 탓 · 정해지지 않은 보상 |
| 배송 지연 | 인정 → 아는 원인 한 줄(있으면) → 현재 상태(아는 만큼) | 확정 도착일 |
| 오배송 · 누락 | 지목 → 인정 → 처리 경로 → 비공개로 확인 | 공개 답글에서 주문 상세 |
| 가격 불만 | 무엇과 비교했는지 받기 → 가격 근거 한 줄(사실 있을 때) | 공개 할인 제안 |
| 사용 어려움 | 인정 → 이미 해 본 것 되짚기 → 새 정보 하나 또는 교환·반품 경로 | 이미 해 본 방법 반복 |
| 리뷰 속 질문 | 판매자 사실로 직접 답 | 질문 건너뛰기 · 사실 없는 답 |
| 안전 · 건강 · 이물 | **사람에게 넘긴다.** 공개 문구는 진지하게 받기 + 직접 확인하겠다 + 연락 경로만 | 인과 인정 · 부정 · 의료 판단 |
| 욕설 · 허위 · 다른 상품 | 신고 검토가 먼저. 답한다면 한 번, 사실만, 다른 구매자를 향해 | 맞대응 · 숨기기 |

## 3. 사람에게 넘기는 것 (초안을 확정하지 않는다)

- 안전 · 건강 · 이물 주장, 법적 · 분쟁 신호(고소 · 소보원 · 공정위), 보상 협의가 필요한 것.
- 답글에 약속 · 원인 설명 · 책임 인정 문장이 들어가면 승인 전에 그 문장을 드러내 보인다. [실무 24]
- 식품 이물 · 화장품 부작용처럼 법정 보고 의무가 걸릴 수 있는 것은 그렇게 표시한다(보고 대상 여부는 법률 검토 필요). [판단 S]

## 4. 정해 주실 것

1. 리뷰 이벤트 안내 전반을 N3에 넣을지(리뷰 대가 제안 금지를 이벤트 안내까지 넓힐지). [법 6절]
2. 반품 안내를 판매자 자체 정책(법보다 긴 기간 등)과 어떻게 합칠지 — 판매자 정책이 법보다 유리하면 판매자 정책, 불리하면 법 기준이 기본안. [법 6절]
3. 문체 기본값(해요체 / 하십시오체). 지금 저장소 규칙은 고객 응대 문장에 합니다체다.
