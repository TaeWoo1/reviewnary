# Reply Standard v2

v1(`../v1/README.md`)을 그대로 잇고 범주 하나를 더했다(2026-11-01 다섯 번째 검토).

- **승계:** v1의 규칙 24개, 범주 9개와 그 `skeleton` · `mustNot`, 넘김 범주(S · L · X), 읽는 법 전부.
- **더함:** 범주 `U` 「사용 전 · 중립」 — 아직 설치 전 · 아직 안 써 봄 · 도착만 확인 · 나중에 후기를 남기겠다는 리뷰. 평가할 내용이
  아직 없다는 것을 **이해한** 경우다. 표현이 모호해 무엇을 말하는지 모르는 경우(판단 불가, `UNSURE`)와 다르다. 응대가 필요한
  범주가 아니고(`needsResponse: false`), 사람에게 넘기지 않는다. 답할지는 판매자의 응대 기준(별점대별 미리 쓰기)이 정한다.
  우선순위는 맨 뒤라, 칭찬이나 아쉬움이 함께 있으면 그 범주가 먼저다.

v1로 쓰인 초안과 채점은 v1로 다시 읽는다. 백엔드는 `backend/src/main/resources/reply-standard/v2/standard.json`에 같은 바이트의
사본을 들고, `ReplyStandardContractTest`가 v1 · v2 둘 다 같음을 고정한다.
